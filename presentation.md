# TCS AI Fridays Hackathon
## Data Engineering Metadata Catalog Description Enhancer

---

## The Problem
### "The Library with Blank Covers"

*   **Data Catalogs** are full of tables with cryptic names (`T_CUST_01`, `TRX_LOG`).
*   **Descriptions are missing** or empty.
*   **Result**: Data Scientists waste hours asking "What is this data?" instead of using it.
*   **Manual Documentation** is slow, boring, and inconsistent.

---

## The Solution
### AI-Powered Metadata Enhancer

An intelligent agent that acts as an **Automated Librarian**.

*   **Reads** technical schemas and raw data.
*   **Understands** context using Generative AI (Google Gemini).
*   **Writes** rich, human-readable descriptions automatically.

---

## How It Works

1.  **Input**: Upload Schema (JSON/DDL) + Sample Data (CSV).
2.  **Process**: The AI analyzes column names, data types, and value patterns.
3.  **Output**: A structured "Metadata Card" with:
    *   Business Overview
    *   Data Quality Insights
    *   Usage Tips
    *   Enriched Field Descriptions

---

## Key Features

*   **🚀 Automated Analysis**: From raw file to documentation in seconds.
*   **🧠 Generative AI**: Powered by Google Gemini 2.0 Flash.
*   **✨ Premium UI**: Modern, dark-mode interface for a great user experience.
*   **💾 Standardized Export**: Download as JSON/XML for easy catalog ingestion.
